一、项目简介

基于 Kaggle 公开数据集（Olist 巴西电商），搭建从数据采集、清洗、分析到可视化的端到端数据分析流水线，模拟企业"用数据驱动增长"的工作流，输出销售趋势、用户价值分层、类目结构、地域分布与交付质量等决策洞察。全程使用公开授权数据，规避直接爬取商业平台的法律与合规风险。

六、快速复现

pip install kagglehub pandas → 依次运行 scripts/download_olist.py、clean_olist.py、analyze_olist.py、eda_olist.py（含品类本地化 localize_categories.py）。

七、局限性与声明

  • 数据来自巴西市场，结论不能直接套用于国内电商，但分析框架可平移；
  • 样本约 25 个月，预测性结论置信度有限；
  • Olist 无显式退货字段，未成交率以订单状态近似；
  • 数据集 © Olist，基于 CC BY-NC-SA 4.0 许可，仅用于学习研究。

项目经验 · 电商商业数据分析

基于 Kaggle 公开数据集（Olist，CC BY-NC-SA 4.0），用 Python 搭建「采集 → 清洗 → EDA → 分析 → 可视化」端到端流水线；以订单为主键聚合 9 张原始表为宽表（9.9 万订单），运用 RFM 用户分层、时间序列趋势、类目/地域结构等方法输出决策洞察，并用 ECharts 搭建交互看板。关键发现：严重迟到订单 77.1% 给低分，定位物流时效为体验瓶颈。全程使用公开授权数据，规避爬虫合规风险。
